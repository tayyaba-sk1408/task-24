
# Day 24 Internship Task: Rock Paper Scissors Game

## Overview

A responsive Rock Paper Scissors game where the player competes against the computer. The computer randomly selects a move, the result is displayed, and the score updates after each round.

## Features

- Rock, Paper, and Scissors choice buttons
- Random computer move
- Win, lose, and draw logic
- Running player and computer scores
- Reset score button
- Displays both moves and the round result
- Responsive design for desktop and mobile screens

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
day-24-rock-paper-scissors/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Create a folder named `day-24-rock-paper-scissors`.
2. Create the four files listed above.
3. Paste the appropriate code into each file.
4. Open `index.html` in your browser.
5. Choose Rock, Paper, or Scissors to play.
6. Click Reset Score to restart the game.

No additional installation is required.

## Game Rules

- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- Matching choices result in a draw.
